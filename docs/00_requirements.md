# 0. 要件定義

## 0.1 背景と位置づけ

物理の数値計算のコードでは、次のような誤りが、実行して結果がおかしくなるまで見つからないことが多い。

- 次元の誤り：$`\mathrm{m}`$ と $`\mathrm{s}`$ を足す、エネルギーを返すはずの式が運動量を返す
- テンソルの構造の誤り：3 次元のベクトルに $`4 \times 4`$ の行列を掛ける、下付きの添字どうしを縮約する、計量テンソルを使わずに添字を上げ下げする
- 座標系の取り違え：極座標の成分とデカルト座標の成分を足す、場の取り方が違う成分どうしを混ぜる
- 対称性の破れ：対称であるはずのテンソルに、対称でない値が入る
- 接続と曲率の誤り：テンソルでない Christoffel 記号をテンソルとして座標変換する、計量テンソルの微分を手で書き間違える

tensorcheck は、これらの誤りを Rust のコンパイル時に止めるライブラリである。座標（空間・時空）のテンソルと、場空間のテンソルを、同じ仕組みで扱う。両方の添字を持つテンソル（例：$`\partial_\mu \phi^I`$）も扱う。

検査は、よく使う数値計算（微分方程式・積分・数値微分）の中でも途切れないようにする。数値解法を外部のライブラリに任せると、値を一度 `f64` の配列に戻して渡すことになり、そこで次元とテンソルの構造の情報が失われるためである。

### 対象とする利用者

| 利用者 | 説明 |
| --- | --- |
| 計算を書く人 | Rust で物理の数値計算・シミュレーションを書く人。Rust の型の仕組みに詳しいとは限らない |
| 拡張する人 | 自分の問題に合わせて、単位系・空間・座標系・計量テンソルを定義する人。多くの場合「計算を書く人」と同じ人 |
| 運営者 | このライブラリを開発・保守する人 |

### 数値計算

どの解法でも、入力と出力は次元とテンソルの構造を持ったまま扱う。次元は次の規則で決まる。

- 積分：$`\int f\,dx`$ の次元は $`[f]\,[x]`$
- 微分：$`df/dx`$ の次元は $`[f]\,/\,[x]`$
- 微分方程式 $`dy/dt = f(t, y)`$：$`f`$ の次元は $`[y]\,/\,[t]`$ でなければならない。$`y`$ は、次元の違う量やテンソルの組（例：位置と速度）でよい

| ID | 要件 | 上位 | 状態 |
| --- | --- | --- | --- |
| FR-18 | 常微分方程式の初期値問題を解ける。解法は、固定刻みの Runge–Kutta 法（4 次）、刻みを自動で調整する陽的 Runge–Kutta 法（Dormand–Prince 5(4)）、シンプレクティック法（leapfrog） | BR-06 | 初期 |
| FR-19 | 硬い常微分方程式を解ける。解法は、刻みを自動で調整する Rosenbrock 法。Jacobi 行列は利用者が与えるか、数値微分（FR-21）で求める | BR-06 | 初期 |
| FR-20 | 1 次元の定積分を求められる。解法は、台形公式、Simpson の公式、Romberg 積分、Gauss–Legendre 求積、適応型の Gauss–Kronrod 求積 | BR-06 | 初期 |
| FR-21 | 関数の微分を数値で求められる（中心差分と、Richardson 補外による精度の改善）。偏微分と Jacobi 行列も求められる | BR-06 | 初期 |
| FR-22 | 解法ごとに、誤差の許容値と打ち切りの条件を指定できる。許容値に届かなかったときは、黙って値を返さず、失敗として知らせる | BR-06 | 初期 |
| FR-23 | 硬い方程式の陰的解法（Radau IIA 法、BDF 法） | BR-06 | 将来 |
| FR-24 | 無限区間・特異点を含む積分、多次元の積分 | BR-06 | 将来 |

## 0.5 コアユースケース（UC）

ユースケースは、Juval Löwy『Righting Software』（Addison-Wesley, 2019）の **The Method** に従って、少数の本質的なものだけに絞る。The Method は、システムを機能ごとではなく「変わりうるもの（変動性）」ごとに分ける設計の方法で、分け方が正しいかを、少数のコアユースケースを構成要素の呼び出しの連なり（コールチェーン）で実現できるかによって確かめる。そのため、機能ごとに 1 つずつユースケースを作ることはしない。ここで挙げたユースケースは、01 と 2b で構成要素の分け方を確かめるのに使う。

| UC-02 | 曲線座標でテンソルを計算する | 計算を書く人 | FR-05, FR-06, FR-07, FR-09, FR-12 |
| UC-03 | 場空間のテンソルを、時空のテンソルと組み合わせて計算する | 計算を書く人 | FR-04, FR-05, FR-06, FR-07, FR-09, FR-10 |
| UC-04 | 座標系を変換する | 計算を書く人 | FR-05, FR-11 |

| UC-06 | 自分の問題に合わせて、単位系・空間・座標系・計量テンソルを定義する | 拡張する人 | FR-02, FR-03, FR-04, FR-05, FR-09 |

FR-14（例題）はユースケースではない。UC-01〜UC-04、UC-07〜UC-09 をそのまま実行できる形にしたものとして扱う。

### UC-01 物理量の式を書いて、次元を検査する
1. 単位を指定して、質量・加速度などの量を作る。
2. 3 次元デカルト座標のベクトルとして、$`F^i = m\,a^i`$ を計算する。
3. 結果の力を、$`\mathrm{N}`$ の単位で取り出す。
4. 次元が合わない式（例：力と加速度を足す）は、コンパイルが通らない（UC-05 へ）。

### UC-02 曲線座標でテンソルを計算する
1. 極座標 $`(r, \theta)`$ を定義する。$`r`$ は長さ、$`\theta`$ は無次元。
2. 座標基底で速度 $`V^a`$ を作る。成分の次元は $`(\mathrm{m\,s^{-1}},\ \mathrm{s^{-1}})`$ になる。
3. 位置に依存する計量テンソル $`g_{ab}`$ を使って、速度の 2 乗 $`g_{ab} V^a V^b`$ を求める。結果は $`\mathrm{m^2\,s^{-2}}`$ のスカラーになる。
4. 座標を型で指定して、$`V^\theta`$ を取り出す。

### UC-03 場空間のテンソルを、時空のテンソルと組み合わせて計算する
1. 4 次元の時空と、2 成分の場空間を定義する。
2. 場空間の計量テンソル $`G_{IJ}(\phi)`$ と、時空の計量テンソル $`\eta_{\mu\nu}`$ を定義する。
3. 場の微分 $`\partial_\mu \phi^I`$（時空の添字と場空間の添字を 1 つずつ持つ）を作る。
4. 運動項 $`G_{IJ}\,\partial_\mu \phi^I\,\partial^\mu \phi^J`$ を求める。時空の添字は $`\eta^{\mu\nu}`$ で上げる。
5. 時空の添字と場空間の添字を縮約しようとすると、コンパイルが通らない。

UC-03 は、教科書にある一般的な非線形シグマ模型の形に留める。

### UC-04 座標系を変換する
1. 極座標とデカルト座標の間の変換（Jacobi 行列 $`\partial x^i / \partial x'^a`$）を与える。
2. 極座標で作ったベクトルを、デカルト座標に変換する。
3. 変換したものは、デカルト座標で作ったものと足せる。変換しないまま足そうとすると、コンパイルが通らない。

### UC-05 誤りのある式を書き、エラー文を読んで直す
1. 誤りのある式を書いて、コンパイルする。
2. エラー文の見出しを読み、誤りの種類（次元・階数と形・添字の上下・座標系・対称性）と、どこが合わないかを知る。
3. 式を直して、コンパイルを通す。

### UC-06 自分の問題に合わせて、単位系・空間・座標系・計量テンソルを定義する
1. 同梱されていない空間（例：3 成分の場空間）や座標系（例：球座標）、単位（例：$`M_\mathrm{P}`$）を定義する。
2. 座標系の各座標の次元と、計量テンソルを与える。
3. ライブラリを書き換えずに、UC-02〜UC-04 と同じ書き方で計算できる。

### UC-07 常微分方程式を解く
1. 状態 $`y`$（例：位置と速度の組）と、右辺 $`f(t, y)`$ を書く。$`f`$ の次元が $`[y]/[t]`$ と合わなければ、コンパイルが通らない。
2. 解法と誤差の許容値を選ぶ。硬い方程式（例：反応の速さが大きく違う化学反応）では、硬い方程式向けの解法を選ぶ。
3. 解いた結果を、次元とテンソルの構造を持ったまま受け取る。許容値に届かなかったときは、失敗として知らせを受け取る。

### UC-08 定積分を求める
1. 被積分関数 $`f(x)`$ と区間を与える。
2. 解法と誤差の許容値を選ぶ。
3. 結果を、次元 $`[f]\,[x]`$ を持った値として受け取る。許容値に届かなかったときは、失敗として知らせを受け取る。

### UC-09 曲がった空間で接続と曲率を求め、測地線を解く
1. 半径 $`a`$ の 2 次元球面を、座標 $`(\theta, \varphi)`$ と計量テンソル $`g = a^2(d\theta^2 + \sin^2\theta\,d\varphi^2)`$ で定義する。成分は、数値の型によらない形で書く。
2. 点 $`p`$ での Christoffel 記号 $`\Gamma^a{}_{bc}(p)`$ を求める。計量テンソルの微分は、自動微分で求まる。
3. Riemann テンソル、Ricci テンソル、スカラー曲率を求める。スカラー曲率は $`R = 2/a^2`$ になる。
4. ベクトル場の共変微分 $`\nabla_b V^a`$ を求める。
5. 測地線の方程式 $`\ddot{x}^a = -\Gamma^a{}_{bc}\,\dot{x}^b \dot{x}^c`$ を、常微分方程式として解く（UC-07）。
6. Christoffel 記号を座標変換しようとしたり、テンソルに足そうとしたりすると、コンパイルが通らない。

## 0.7 スコープ外

- スピノル、Grassmann 数（テンソルとは変換の規則が違う）
- 実行時に階数や次元数が決まるテンソル（コンパイル時の検査という目的と両立しない）
- 微分形式と外微分（反対称テンソル（FR-10）で表せる範囲に留める）
- 偏微分方程式の解法、境界値問題、最適化、乱数・統計、FFT
- 可視化、GPU での計算
- 線形代数の一般的な処理（行列の分解、固有値など）。ただし、計量テンソルの逆（FR-09）、Jacobi 行列の逆（FR-11）、硬い方程式の解法（FR-19）に要る小さな行列の逆と連立一次方程式の解法は、内部に持つ。次元数が 4 以下の逆行列は、余因子行列による解析的な式で求める
