# 0. 要件定義

## 0.1 背景と位置づけ

物理の数値計算のコードでは、次のような誤りが、実行して結果がおかしくなるまで見つからないことが多い。

- 次元の誤り：m と s を足す、エネルギーを返すはずの式が運動量を返す
- テンソルの構造の誤り：3 次元のベクトルに 4×4 の行列を掛ける、下付きの添字どうしを縮約する、計量を使わずに添字を上げ下げする
- 座標系の取り違え：極座標の成分とデカルト座標の成分を足す、場の取り方が違う成分どうしを混ぜる
- 対称性の破れ：対称であるはずのテンソルに、対称でない値が入る

tensorcheck は、これらの誤りを Rust のコンパイル時に止めるライブラリである。座標（空間・時空）のテンソルと、場空間のテンソルを、同じ仕組みで扱う。両方の添字を持つテンソル（例：∂_μ φ^I）も扱う。

このライブラリは、副業のぬこの制作物でもある。ホームページで、通るコードとコンパイルエラーになるコードを並べて解説する。

### 対象とする利用者

| 利用者 | 説明 |
| --- | --- |
| 計算を書く人 | Rust で物理の数値計算・シミュレーションを書く人。Rust の型の仕組みに詳しいとは限らない |
| 拡張する人 | 自分の問題に合わせて、単位系・空間・座標系・計量を定義する人。多くの場合「計算を書く人」と同じ人 |
| 運営者 | このライブラリを開発・保守する人（副業のぬこ） |

## 0.2 ビジネス要件（BR）

| ID | 要件 |
| --- | --- |
| BR-01 | 物理の数値計算で起きる誤り（次元・テンソルの構造・座標系・対称性）を、実行する前（コンパイル時）に見つけられるようにする |
| BR-02 | 座標のテンソルと場空間のテンソルを、同じ仕組みで扱えるようにする |
| BR-03 | Rust の型の仕組みに詳しくない人にも、誤りの内容がわかるようにする |
| BR-04 | 単位系・空間・座標系・計量など、問題ごとに違うものに、ライブラリを書き換えずに対応できる |
| BR-05 | 検査のために、計算を遅くしたり、メモリを余計に使ったりしない |
| BR-06 | 制作物として、運営者の能力（型による設計、数値計算、設計の進め方）を示す |
| BR-07 | 運営者の個人情報や、運営者が分けている別の活動の情報を含めない |

## 0.5 コアユースケース（UC）

The Method に従い、ユースケースは少数の本質的なものだけに絞る。機能ごとに 1 つずつ作ることはしない。これらは、01 の構成要素の分け方が正しいかを確かめるためにも使う（コールチェーンで検証する）。

| ID | ユースケース | アクター | 実現する FR |
| --- | --- | --- | --- |
| UC-01 | 物理量の式を書いて、次元を検査する | 計算を書く人 | FR-01, FR-02, FR-03, FR-06, FR-08 |
| UC-02 | 曲線座標でテンソルを計算する | 計算を書く人 | FR-05, FR-06, FR-07, FR-09, FR-12 |
| UC-03 | 場空間のテンソルを、時空のテンソルと組み合わせて計算する | 計算を書く人 | FR-04, FR-05, FR-06, FR-07, FR-09, FR-10 |
| UC-04 | 座標系を変換する | 計算を書く人 | FR-05, FR-11 |
| UC-05 | 誤りのある式を書き、エラー文を読んで直す | 計算を書く人 | FR-13 |
| UC-06 | 自分の問題に合わせて、単位系・空間・座標系・計量を定義する | 拡張する人 | FR-02, FR-04, FR-05, FR-09 |

FR-14（例題）はユースケースではない。UC-01〜UC-04 をそのまま実行できる形にしたものとして扱う。

### UC-01 物理量の式を書いて、次元を検査する
1. 単位を指定して、質量・加速度などの量を作る。
2. 3 次元デカルト座標のベクトルとして、F = m a を計算する。
3. 結果の力を、N の単位で取り出す。
4. 次元が合わない式（例：力と加速度を足す）は、コンパイルが通らない（UC-05 へ）。

### UC-02 曲線座標でテンソルを計算する
1. 極座標 (r, θ) を定義する。r は長さ、θ は無次元。
2. 座標基底で速度 V^a を作る。成分の次元は (m/s, 1/s) になる。
3. 位置に依存する計量 g_ab を使って、速度の 2 乗 g_ab V^a V^b を求める。結果は m²/s² のスカラーになる。
4. 座標を型で指定して、V^θ を取り出す。

### UC-03 場空間のテンソルを、時空のテンソルと組み合わせて計算する
1. 4 次元の時空と、2 成分の場空間を定義する。
2. 場空間の計量 G_IJ(φ) と、時空の計量 η_μν を定義する。
3. 場の微分 ∂_μ φ^I（時空の添字と場空間の添字を 1 つずつ持つ）を作る。
4. 運動項 G_IJ ∂_μ φ^I ∂^μ φ^J を求める。時空の添字は η で上げる。
5. 時空の添字と場空間の添字を縮約しようとすると、コンパイルが通らない。

UC-03 は、教科書にある一般的な非線形シグマ模型の形に留める。

### UC-04 座標系を変換する
1. 極座標とデカルト座標の間の変換（ヤコビ行列）を与える。
2. 極座標で作ったベクトルを、デカルト座標に変換する。
3. 変換したものは、デカルト座標で作ったものと足せる。変換しないまま足そうとすると、コンパイルが通らない。

### UC-05 誤りのある式を書き、エラー文を読んで直す
1. 誤りのある式を書いて、コンパイルする。
2. エラー文の見出しを読み、誤りの種類（次元・階数と形・添字の上下・座標系・対称性）と、どこが合わないかを知る。
3. 式を直して、コンパイルを通す。

### UC-06 自分の問題に合わせて、単位系・空間・座標系・計量を定義する
1. 同梱されていない空間（例：3 成分の場空間）や座標系（例：球座標）を定義する。
2. 座標系の各座標の次元と、計量を与える。
3. ライブラリを書き換えずに、UC-02〜UC-04 と同じ書き方で計算できる。

## 0.7 スコープ外

- スピノル、Grassmann 数（テンソルとは変換の規則が違う）
- 実行時に階数や次元数が決まるテンソル（コンパイル時の検査という目的と両立しない）
- 微分形式と外微分（反対称テンソル（FR-10）で表せる範囲に留める）
- 数値解法（微分方程式のソルバーなど）、可視化、GPU での計算
- 線形代数の高度な処理（行列の分解、固有値など）。必要になったら、成分を取り出して他のクレートに渡す
